# 🏖️ AER — Anandamayee Eco Resort

### Scroll-Driven 3D Villa Experience | At Sea Beach

> **Nature. Serenity. Sustainability.**

A premium, immersive website for Anandamayee Eco Resort featuring a **scroll-driven 3D villa model** built with Three.js, glassmorphic UI with a **Pearl & Champagne** color palette, and GSAP-powered animations.

---

## ✨ Features

- 🏠 **3D Resort Model** — Full Three.js scene with 12+ eco-cottages, palm trees, pathways
- 🎬 **Scroll-Driven Animation** — Scrolling rotates the model, revealing each side with info panels
- 🪟 **Glassmorphism Design** — Frosted glass cards, inputs, and navigation
- 🎨 **Pearl & Champagne Palette** — Premium, rich color scheme
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile
- 🖱️ **Custom Cursor** — Champagne-gold interactive cursor
- 🖼️ **Photo Gallery** — Real construction site images
- 🎥 **Video Walkthrough** — Embedded site tour video

## 🚀 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/YOUR_USERNAME/aer-resort-3d.git
   cd aer-resort-3d
   ```

2. Open in VS Code and install the **Live Server** extension.

3. Right-click `index.html` → **"Open with Live Server"**

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Three.js | 3D rendering |
| GSAP + ScrollTrigger | Scroll-driven animations |
| HTML5 / CSS3 | Structure & glassmorphic styling |
| Vanilla JS | Interactions & logic |
